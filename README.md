10. 新生兒數據分析專案
   - 專案簡介：本專案旨在分析 1880 年至 2020 年間的新生兒數據，包含男嬰、女嬰的總數、姓名多樣性等統計資訊
   - 關鍵技術：
     1. 檔案處理
        - 使用 open() 與 readlines() 逐行讀取檔案
        - 使用 split(',') 將 CSV 格式的資料分割為結構化數據
     2. 數據處理
        - 使用迴圈與條件判斷（if）進行數據篩選與累加
        - 計算 Shannon 多樣性指數以量化姓名的多樣性
     3. 資料視覺化
        - 使用 matplotlib 繪製折線圖，直觀展示數據趨勢
     4. 模組化設計
        - 每個功能（如計算男嬰總數、計算多樣性）封裝為獨立函數，便於維護與擴展
